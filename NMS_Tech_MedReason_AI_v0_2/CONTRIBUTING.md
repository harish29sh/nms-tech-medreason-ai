# Contributing

This is a proprietary NMS Tech repository. Contributions require authorization.

Contributors must:
1. Use only synthetic/de-identified clinical test data.
2. Avoid copying textbook or guideline wording into source files.
3. Add external medical sources as link-only unless a licence review permits ingestion.
4. Preserve NMS Tech ownership notices and third-party attribution.
5. Add tests for new clinical/safety functionality.
