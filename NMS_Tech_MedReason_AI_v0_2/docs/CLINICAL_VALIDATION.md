# Clinical Validation Plan

Do not deploy v0.2 for autonomous clinical use. Build a clinician-reviewed benchmark for each complaint covering expected syndrome, must-not-miss diagnoses, top differential set, red flags, history/examination, tests, unsafe outputs and verified references.

Suggested metrics: dangerous-diagnosis recall, top-3 differential coverage, emergency flag recall, unsupported recommendation rate, citation validity, dose-guard effectiveness and clinician usability/time saved.
